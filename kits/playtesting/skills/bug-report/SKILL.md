---
name: bug-report
description: Write a reproducible bug report with severity. Use when a defect is found or described.
---

```
## Bug: <one-line summary>
Severity: S1 | S2 | S3 | S4   (see the Playtesting kit's scale)
Build/commit: <sha>
Steps to reproduce:
1. ...
Expected: ...
Actual: ...
Reproducibility: always | often | rarely | once
Evidence: <log excerpt, screenshot path, file:line>
Suspected cause: <optional, marked as a guess unless verified>
```

If you cannot reproduce it, say so and record what you tried.
